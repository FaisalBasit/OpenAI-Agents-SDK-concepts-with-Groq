# OpenAI Agents SDK Concepts with Groq

A hands-on Python learning repository demonstrating OpenAI Agents SDK concepts using Groq's OpenAI-compatible API.

## Concepts

- Agents
- Custom tools
- Agent handoffs
- Structured output with Pydantic
- Triage agents
- Safety guardrails

## Technology

Python, OpenAI Agents SDK, Groq API, Pydantic, and python-dotenv.

## Setup

Create a virtual environment, install the requirements, and configure GROQ_API_KEY in a .env file. Run the individual concept examples with Python.
